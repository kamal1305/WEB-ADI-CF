# A.D. Icovesa — Web Oficial

Sitio estático de A.D. Icovesa con información de equipos, calendario, clasificaciones (RFAF), tienda, galería y más.

**Hosted on GitHub Pages:** https://kamal1305.github.io/WEB-ADI-CF/

## Estructura

- `index.html` — Página principal (SPA client-side)
- `content/` — JSONs con datos del club (calendario, equipos, clasificaciones, tienda, etc.)
- `img/` — Imágenes del club
- `admin/` — Panel de administración (Decap CMS, local_backend para desarrollo)

## Actualizar datos

Los JSONs en `content/` se pueden editar manualmente o desde el panel `/admin/` en local.
